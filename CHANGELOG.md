## [2.0.0] - 2026-11-07
Brand refresh. No API, database, or configuration changes; a rolling upgrade from 1.0.0 is safe.

### Added
- Official ReliefGrid logo set: full, compact, transparent (dark surfaces), light-surface, horizontal lockup, emblem mark, and GitHub social preview
- App icon set: favicon, 192/512 px, maskable, and Apple touch icon
- `Logo` component, shown on the landing page and dashboard header
- Light/dark logo switching in the README

### Changed
- PWA manifest icons and splash background now use the new brand
- Wordmark in the light-surface logo uses the app's ink and teal palette; the orange pin is the single warm accent
